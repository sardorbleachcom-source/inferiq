# Inferiq Website

Inferiq uchun animatsiyali Liquid Glass landing page.

## Fayllar
- `index.html` — sayt tuzilmasi
- `style.css` — Liquid Glass dizayn, animatsiyalar va mobil moslashuv
- `script.js` — o‘zbek/rus/ingliz tillari, dark/light rejimi va animatsiyalar

## Ishga tushirish
`index.html` faylini brauzerda oching. Sayt oddiy statik veb-sayt bo‘lib, dastlabki ko‘rish uchun server talab qilmaydi.

## Sozlash
- Telegram havolalarini `index.html` ichida o‘zgartiring.
- Tarjimalar `script.js` ichidagi `translations` obyektida.
- Ranglar va effektlar `style.css` ichidagi CSS o‘zgaruvchilarida.

Til va fon rejimi `localStorage` orqali saqlanadi. Google Fonts ishlashi uchun internet kerak bo‘lishi mumkin.
